RustCraft

Procedural Minecraft-like sandbox

Controls

  • WASD Move
  • Mouse Look around
  • Space Jump
  • Shift Sprint
  • F5 / C First / third / front camera
  • E Inventory & crafting
  • T Chat
  • Left click Break block / hit mob
  • Right click Place block / use
  • 1-9 / Wheel Select hotbar slot
  • Esc Pause / close UI

What's inside

Biomes, caves, ores, villages, temples, shipwrecks, mineshafts, trees, day & night, pixel textures, block shadows, ambient occlusion, a hotbar, creative items, and sheep, cows, pigs, chickens, zombies, skeletons, creepers, spiders and endermen.

The game runs entirely in your browser. LAN multiplayer is desktop-only.
